# Workm Planner Neon Ultimate Pro

A neon weekly timetable and life planner that runs in the browser. Your data stays in `localStorage`.

## What’s inside

- **Schedule** — week grid, click a slot, repeating blocks with person, room, and color
- **Today** — now / next with countdown
- **Tasks** — priorities and due dates
- **Notes** — neon sticky notes
- **Month** — calendar with event dots
- **Habits** — 7-day tracker
- **Religion** — prayer times, next-prayer, hijri date, streak, tasbih
- **Clocks & Focus** — stopwatch, countdown timer, pomodoro, alarms
- **Calculator** — with history
- **English / Arabic / Urdu**
- **Export** JSON or CSV, **import** backup, **print**
- Neon themes, PIN lock, search, optional reminders and sounds
