# Workm Planner Neon Ultimate Pro

A neon timetable web app for planning work, study, and daily routines — all in one page, saved in your browser.

## Features

- Weekly timetable with click-to-add events
- Recurring weekly blocks and one-off dated events
- Religion schedule with daily prayer tracker
- Stopwatch with laps
- Calculator
- English, Arabic, and Urdu
- Export / import JSON backup
- Profile, work hours, and optional 5-minute reminders

Open `index.html` in a browser, or serve the folder with any static file server. Data stays in `localStorage`.
